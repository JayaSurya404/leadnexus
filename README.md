# LeadNexus

LeadNexus is a production-oriented MVP foundation built with the Next.js App Router, TypeScript, Tailwind CSS, shadcn/ui, Supabase PostgreSQL, Supabase Auth, Supabase Storage, Supabase Row Level Security (RLS), and Vercel deployment.

## Product users

1. Platform Admin
2. Business Owner
3. Public Lead

## Future modules

- Business public pages
- Products and services
- Lead capture
- Tracking links
- Visitor activity tracking
- Direct contact tracking
- AI Lead Intelligence
- Hot/Warm/Cold scoring
- Lead Recovery
- Owner leads
- Admin intelligence
- Analytics
- SEO
- Future VoiceNexus lead handoff

Phone calling is **not** part of LeadNexus.

## Development

Copy `.env.example` to `.env.local`, configure credentials when integrations are implemented, then run `npm run dev`. Placeholder routes and tests intentionally remain unimplemented until the business-feature phase.
